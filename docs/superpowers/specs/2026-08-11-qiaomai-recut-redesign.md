# 《荞麦疯长》recap 重制设计 — 重新剪辑 + 重写解说词

日期: 2026-08-11
状态: 已确认
项目: video-recap-skills / 电影《荞麦疯长》(Wild Grass, 2020, 徐展雄导演)

## 背景与问题

上一版 recap 成片存在三个根本问题（用户反馈）:

1. **解说词与剧情不吻合**: 解说词讲述了完整的三线命运(车祸/卖身/牺牲/火拼), 但画面里根本没有这些情节。
2. **故事情节不完整**: 当前 clip_plan 只是源视频 0-1200s 的连续切片(原片前 20 分钟直出), 李麦线(1350s+)和吴风线(3000s+)完全缺失。
3. **视频片段不能重复** + **时间轴顺序不能变**: 新剪辑必须按源时间轴单调递增选段, 互不重叠。

根因: 上一版剪辑阶段没有真正挑选片段(连续切片), 而解说词是按"完整电影剧情"凭空编写的, 导致解说与画面严重错位(如 148s 画面在"结账"却解说"被玷污"; 679s 画面只有音乐却解说"帮派火拼")。

## 需求(用户确认)

1. 解说词重新整理, 整体连贯, 与视频剧情严格吻合
2. 故事情节完整(剪辑完整性)
3. 视频片段不重复
4. 视频时间轴顺序不变

## 方案

重新剪辑: 从 89 分钟全片按**源时间轴顺序**挑选关键情节片段(单调递增、互不重叠), 覆盖三线完整故事, 拼成 **25 分钟(1500s)**; 再按新画面时间轴**重写解说词**(纪录片冷静风, 连贯、与剧情吻合); TTS 重新合成; 装配重渲染。

## 执行路径

1. 生成新 `clip_plan.json`(1500s, 上述选段)
2. `video-cut` 重剪辑 → 新 `edited_source.mp4`(1500s)
3. 按新画面时间轴重写 `narration.json`(解说词严格对应每个片段的实际画面, 纪录片冷静风, 连贯完整)
4. `validate.py` 校验(时间轴/语速/对白重叠)
5. `video-voiceover` TTS 重新合成(文本已变, 需重新生成)
6. `video-assemble` 重渲染(混音/压原声/字幕) → 新成片
7. QC 验证(assembly_qc PASS, timeline 无 unsafe entry)
